How to combine videos on a Mac

Several short clips from the same day often work better as one video. Here is how to join them on your Mac, in your order.

With Bubbleshift

  1. Select the videos in Finder and start dragging them.
  2. Tap ⌘ Command while dragging and drop on Merge (it reads Join into one video).
  3. Drag the clips into the order you want, then click Merge. One video appears beside the first clip.

With what macOS already has

Open the first video in QuickTime Player, choose Edit → Add Clip to End, pick the next clip, repeat, then choose File → Export As. iMovie can do it too, in a project.

Why use Bubbleshift for this

You join clips straight from Finder and set the order visually. Clips of a different size are fitted into the first clip's frame, and the originals are left as they are.

Questions

Can I combine videos of different sizes?

Yes. Each clip is fitted into the first clip's frame, centered, so nothing is stretched.

Which format is the result?

MOV if the first clip is a MOV, otherwise MP4.

Can I join audio files the same way?

Yes. Drag the tracks, tap Command and drop on Merge to get one track.

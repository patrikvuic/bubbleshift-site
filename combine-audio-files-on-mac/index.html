How to combine audio files on a Mac

Several voice memos, parts of an interview or a playlist of clips: here is how to join them into one audio file on your Mac.

With Bubbleshift

  1. Select the audio files in Finder and start dragging them.
  2. Tap ⌘ Command while dragging and drop on Merge (it reads Join into one track).
  3. Drag the tracks into the order you want, then click Merge. One track appears beside the first file.

With what macOS already has

Open the first file in QuickTime Player, choose Edit → Add Clip to End for each of the others, then File → Export As → Audio Only. GarageBand works too.

Why use Bubbleshift for this

It starts from a Finder drag, the order is set visually, and when every file is WAV, AIFF or FLAC of the same type the result stays lossless. Mixed formats become one M4A.

Questions

Which format is the result?

The same format when all files are WAV, AIFF or FLAC of one type; otherwise M4A.

Can I trim the tracks first?

Yes. Use Trim on each file, then join them.

Is anything uploaded?

No.
